# 🧸 TinyLearn — Learn • Play • Grow

A vibrant, playful, and interactive web application designed for young children aged 3–8 to learn **English (ABCD / A–Z)**, **Numbers (1–20)**, and **Hindi (अ–ज्ञ)** with voice audio, 3D tactile toy blocks, cartoon animations, letter tracing, and rewarding game shows!

---

## 🌟 Features

- 🧸 **Tiko the Teddy Mascot**: Animated mascot with expressive emotional states and synchronized voice speech bubbles in English & Hindi.
- 🧱 **3D Tactile Toy Block Aesthetics**: Child-friendly 3D physical blocks, candy buttons, and Google bubble fonts (*Baloo 2*, *Fredoka*, *Nunito*, *Noto Sans Devanagari*).
- 🔤 **ABC Adventure (English Module)**:
  - 3D interactive alphabet blocks with phonics and pronunciations.
  - **Crayon Box Drawing Studio**: Interactive digital canvas for practicing letter tracing with wax crayons.
  - Interactive mini-games: *Find the Letter* and *Match Object to Letter*.
- 🔢 **Number Playground (Math Module)**:
  - 1 to 20 balloon counting blocks with countable objects and audio count-ups.
  - **Missing Number Train 🚂**: Complete the number sequence.
  - **Number Showdown 💥**: Compare and find the bigger number.
- 🇮🇳 **हिंदी की दुनिया (Hindi Varnamala Module)**:
  - Swar (स्वर - अ to अः) and Vyanjan (व्यंजन - क to ज्ञ) Devanagari blocks with authentic voice speech.
  - Interactive games: *शब्द पहचानें*, *चित्र और अक्षर मिलाओ*, and *अक्षर खोजो*.
- 🎮 **Tiko's Quiz Game Show**: Practice mode with live Star Energy meter, praise cues, and fanfare celebrations.
- 🌈 **Adventure Trail Map & 🏆 My Treasure Box**: Checkpoint trail and unlockable collectible achievement badges.
- 🛡️ **Parent & Educator Zone**: Child-safe math lock gate (`8 + 7 = 15`), learning minutes tracking, and subject mastery breakdown.

## 🚀 Getting Started

### Prerequisites
- Node.js (v18+)
- npm

### Installation
```bash
# Clone the repository
git clone https://github.com/RiteshBhaskar/TinyLearn.git

# Navigate into the project folder
cd TinyLearn

# Install dependencies
npm install

# Start local dev server
npm run dev
```

### Production Build
```bash
npm run build
```

## ☁️ Deployment on Netlify

This project is pre-configured for **Netlify** with `netlify.toml` and `public/_redirects`.

1. Push this repository to your GitHub account: `https://github.com/RiteshBhaskar`
2. Go to [Netlify](https://app.netlify.com/) and click **"Add new site"** → **"Import an existing project"**.
3. Select **GitHub** and choose your repository.
4. Build Settings (auto-detected via `netlify.toml`):
   - **Build command**: `npm run build`
   - **Publish directory**: `dist`
5. Click **"Deploy TinyLearn"**!
